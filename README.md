# Academic website: Md. Shahinur Rahman

A fast, static academic website (plain HTML and CSS, no build step, no tracking).

## Publish on GitHub Pages (free and permanent)
1. Create a free account at github.com. Choose your username carefully, because it becomes your address (for example `shahinurrahman` gives `https://shahinurrahman.github.io`).
2. Click **New repository**. Name it exactly `YOUR-USERNAME.github.io`, set it to **Public**, and create it.
3. Click **Add file > Upload files**, drag in everything from this folder (including the `assets` folder and the hidden `.nojekyll` file), and click **Commit changes**.
4. Open **Settings > Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save.
5. After one to two minutes your site is live at `https://YOUR-USERNAME.github.io`.
6. In `robots.txt` and `sitemap.xml`, replace `YOUR-USERNAME` with your username, then commit.

## Make it easy to find
- Add the address to your Google Scholar, ORCID, Scopus, university profile, LinkedIn and email signature.
- In Google Search Console, add the site and submit `sitemap.xml`.

## Update it
Open `index.html` on GitHub, click the pencil icon, edit the text, and commit. To add a publication, copy one `<li>` in the Publications section and change the text.

## Optional: your own domain
Buy a domain, add a file named `CNAME` containing only the domain, then follow GitHub's custom domain steps under **Settings > Pages**.

## Privacy
Only publish what you want public. This site lists emails but no phone number, ID numbers or home address.
